# 3-minute demo script

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:20 | Landing page | After an accident people don't know what to send, which means avoidable back-and-forth for claims teams. |
| 0:20–0:55 | Start report, enter details, upload synthetic photos | A guided first-notice-of-loss flow with an evidence checklist. |
| 0:55–1:30 | AI help; on-device badge | For supported tasks Firebase AI Logic prefers the on-device model, so first-pass help can stay on the device. |
| 1:30–2:00 | `/lab` with "Only cloud", or a browser without the model | When local isn't available, the same call falls back to the cloud. The app always shows which route ran, and why. |
| 2:00–2:35 | Edit the AI draft, review, submit | The model never decides a claim. It organises details and flags what's missing; the customer confirms. |
| 2:35–3:00 | Officer queue → case → audit trail | The officer sees the original statement beside the AI draft, with a traceable record. Local-first AI for a real claims workflow. |

Record in English on a rehearsed machine, with synthetic data, notifications off, under 3:00.
